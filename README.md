# pc-labo-js-react-intro

[PC-LABO](https://pc-labo.online/) の「PC-LABOを試すためのJavaScript・React入門」（全3回）で使うコードをまとめたリポジトリです。

「Reactで学ぶ 予定管理アプリ開発」シリーズの前提知識として、JavaScriptとReactの基本を先に押さえることを目的にしています。

## 記事とフォルダの対応

| 回 | 内容 | フォルダ |
| --- | --- | --- |
| 第1回 | 変数・型・条件分岐・ループ・関数 | `01_javascript-basics` |
| 第2回 | Reactで頻出するJavaScript | `02_javascript-for-react` |
| 第3回 | React入門 | `03_react-basics` |

## 使い方

1. このリポジトリのページで「Code」→「Codespaces」→「Create codespace on main」を選ぶ
2. ターミナルで、動かしたい回のフォルダに移動して実行する

```bash
cd 01_javascript-basics
node basics.js
```

Node.js 22 が入った環境が自動で用意されます（`.devcontainer/devcontainer.json`）。
